# Portafolio personal: Angela Becerra

🔗 **Sitio publicado:** https://angela2201.github.io/portafolio/

## Descripción

El sitio presenta mi perfil profesional a futuros empleadores. Incluye:

- Presentación y datos de contacto.
- Sobre mí, habilidades técnicas y blandas, idiomas.
- Experiencia laboral y formación académica.
- Proyectos destacados.
- Formulario de contacto con validación.

## Tecnologías

- HTML5
- CSS3 (archivo externo, diseño en cuadrícula y adaptación a pantallas)
- JavaScript puro (sin frameworks ni librerías)
- Tipografías de Google Fonts: Poppins, Inter y JetBrains Mono
- Git y GitHub Pages para la publicación

## Funcionalidades de JavaScript

- **Menú activo:** resalta la sección que se está viendo al desplazarse.
- **Validación del formulario:** revisa nombre, correo y mensaje con `alert()`.
- **Botón de habilidades:** oculta y muestra la tarjeta de habilidades blandas.

## Cómo ver el proyecto en tu computador

1. Descarga o clona este repositorio.
2. Abre el archivo `index.html` con tu navegador.

No necesita instalación ni servidor, porque es un sitio estático.
